# Spec: free Job Application Tracker (UK)

Date: 1 October 2026 · Status: draft for approval · Page: `/tools/job-application-tracker-uk`

## 1. Why build it

- **Demand:** "job application tracker" gets 100–1K UK searches a month with **low** competition (Google Keyword Planner, Sep 2025–Aug 2026). High ad bids show commercial intent.
- **Right audience:** people who track applications are applying to many jobs, which is exactly the Job Search Pass buyer (£24.99 once, unlimited tailored CVs and letters for 90 days).
- **Natural next step:** every tracked job is a reason to tailor a CV. The tracker can hand each job to our existing tools, and that is where the Pass sells.

**Success measures (first 8 weeks after indexing):**
- The page ranks on page 1 for "job application tracker" and "job application tracker UK".
- At least 15% of visitors add a job; at least 10% of those who add 3+ jobs click "Tailor my CV for this job".
- Pass checkouts started from tracker placements are visible in the growth report.

## 2. What already ranks, and our angle

| Competitor | What it is | Weakness we can use |
|---|---|---|
| Simplify, Huntr-style apps | Account + browser extension, US-first | Signup needed; US wording and job boards |
| ApplyArc, My Job Trackr | UK apps, free tier, Pro £19/month or £2.99/month | Subscription upsell; account required |
| JobTrack | Free, public-sector only | Narrow audience |
| Spreadsheet templates (Spreadsheet Daddy, Workzil, ApplyArc) | Excel / Google Sheets downloads | Manual; no link to tailoring a CV |

**Our angle:** *free, no signup, UK-specific, and each job links straight to a tailored CV and cover letter.* No competitor connects tracking to tailoring.

## 3. How to build it (recommended approach)

**Browser-only tool, no account.** The page is server-rendered for SEO; the tracker itself is a client component that stores jobs in the visitor's browser (`localStorage`).

Why this way:
- No signup, which matches what searchers expect and what competitors offer free.
- No database, API or GDPR burden: job data never leaves the device. This also makes it fast to ship.
- Reuses existing patterns: the tool page layout, `TrackedLink` placements, the career-tool handoff, and `PassOffer`.

Trade-off: data lives in one browser. This is mitigated by **CSV export/import** and a clear note. Syncing to a WorkCV account is a possible phase 2 if usage justifies it.

Also ship a **free downloadable Excel template** (`public/downloads/job-application-tracker-uk.xlsx`, generated by a committed script) for people who search for a spreadsheet. It's the same columns and status dropdown.

## 4. MVP features

**Add / edit a job** (only role and employer are required):
- Job title, employer, location, salary (free text), job advert link, where found (Indeed, Reed, Totaljobs, CV-Library, LinkedIn, NHS Jobs, Civil Service Jobs, company site, agency, other), closing date, date applied, status, next action and date, contact name, notes, and optionally the job advert text (used for tailoring).

**Statuses (UK wording):** Saved · Applied · Interview · Offer · Unsuccessful · Withdrawn.

**Views:**
- Desktop: columns by status, each with a count.
- Mobile: one list with status filter chips.
- Sort by next action date; overdue follow-ups and closing dates within 3 days get a visible badge.

**Summary strip:** applications this week, active applications, interviews, follow-ups due.

**Export and import:**
- Export CSV (opens in Excel/Google Sheets).
- Print-friendly log (date, employer, role, status, where found), which job seekers can use as a record of their job search.
- Import CSV, so people can move from the spreadsheet template or another device.

**Tailor this job** (the Pass link):
- Each job has "Tailor my CV for this job".
- It opens the existing Job Application Pack tool pre-filled with role, employer and advert text, so the visitor gets tailored bullets and a cover-letter draft and then continues into the editor.
- No new AI cost path; it reuses the pack's existing flow.

**Contextual Pass offer:**
- Once 3 or more jobs are tracked, show a compact Pass offer: "You're applying to N jobs. Tailor a CV and cover letter for each: £24.99 once, 90 days."
- Below 3 jobs, show the standard single-CV route.

**Empty state:** a short 3-row example the visitor can load and then clear, so the value is visible instantly.

**Data controls:** "Your jobs are saved only in this browser", export reminder after 5+ jobs, "Delete all" with confirmation.

**Out of scope for MVP:** accounts and syncing, browser extension, email reminders, job search or scraping, interview scheduling, AI features inside the tracker.

## 5. Data model and storage

```ts
type TrackedJob = {
  id: string;                 // crypto.randomUUID()
  role: string;               // required, ≤120
  employer: string;           // required, ≤120
  location?: string; salary?: string; url?: string; source?: JobSource;
  closingDate?: string; appliedDate?: string;          // YYYY-MM-DD
  status: "saved" | "applied" | "interview" | "offer" | "unsuccessful" | "withdrawn";
  nextAction?: string; nextActionDate?: string;
  contact?: string; notes?: string;                    // ≤2,000
  advertText?: string;                                 // ≤30,000 (matches handoff limit)
  createdAt: number; updatedAt: number;
};
```

- **Storage:** key `workcv-job-tracker-v1`, value `{ version: 1, jobs: TrackedJob[] }`, validated with zod on read. Invalid entries are dropped, not crashed on.
- **Limits:** 300 jobs, with a friendly message at the limit.
- **Robustness:** all storage access wrapped in try/catch. If storage is blocked (private mode), the tool still works for the session and says so.
- **URLs:** only `http(s)` URLs are rendered as links.
- **CSV safety:** escape quotes and commas. Prefix cells starting with `= + - @` with `'` to prevent spreadsheet formula injection.

## 6. Page content (SEO and AI citations)

- **Title:** "Free Job Application Tracker UK – No Signup | WorkCV"
- **H1:** "Free job application tracker for UK job seekers"
- **Meta description:** "Track every job you apply for: status, follow-ups and closing dates. Free, no signup, saved in your browser. Export to Excel and tailor your CV for each role."
- **Above the fold:** the tool itself (no long intro); one line of reassurance ("No signup · Saved only on this device · Export any time").
- **Below the tool:**
  - What to track for each application, and why.
  - A simple weekly routine (review follow-ups, tailor before applying).
  - Tailoring your CV for each job (links to the ATS checker and Job Application Pack).
  - A free Excel template download.
  - Keeping a record of your job search. Mention Universal Credit job search records only with a checked GOV.UK source, and don't imply the export is an official form.
- **FAQ (schema):** Is it free? Where is my data stored? Can I use it in Excel/Google Sheets? How many jobs should I apply for? Can I tailor my CV for each job?
- **Schema:** `WebApplication` (free, `offers.price: 0`), `FAQPage`, breadcrumbs.
- **Internal links in:** tools hub, career tools hub, footer, sitemap, the redundancy calculator, `/situations/made-redundant`, the ATS checker, the Job Application Pack and the right-to-work guide.

## 7. Analytics

- **New CTA placements:** `tracker_tailor_job`, `tracker_pass_offer`, `tracker_template_download`, `tracker_editor`.
- **Funnel events** (existing first-party funnel, no job content ever sent):
  - jobs-added count bucket (1, 3, 5, 10+);
  - CSV export or import;
  - print log;
  - Pass offer shown and clicked.
- The growth report should then answer: tracker visitors → added a job → tailored a job → Pass checkout.

## 8. Privacy and copy

- **Privacy policy:** add a short line saying the tracker stores entries only in the visitor's browser; WorkCV does not receive them unless the visitor chooses "Tailor my CV", which passes that one job's details into the tools they open.
- **Honest claims only:** no "proven to get you hired", and no implying the log is an official Jobcentre document.

## 9. Testing

- **Unit (node:test):**
  - storage parse and validation (bad JSON, unknown fields, over-limit);
  - CSV export escaping and formula-injection guard;
  - CSV import round-trip;
  - summary counts and overdue logic;
  - the tailoring handoff builds a valid patch.
- **Browser check (Playwright, desktop and 375px):**
  - add, edit and move jobs;
  - reload persistence;
  - export and import;
  - the Tailor button pre-fills the Job Application Pack;
  - the Pass offer appears at 3 jobs;
  - no horizontal overflow.
- **Content test:** the guard against outdated offer copy (`tests/offer-copy.test.ts`) covers the new page automatically.

| Step | Effort |

| Page content, schema, Excel template, internal links | 0.5 day |
| Review, browser checks, deploy | 0.5 day |

**Rollout:**
1. Deploy, then request indexing.
2. Add the page to the link kit.
3. Post it in relevant threads where people ask how to track applications, with a disclosure line.
4. Review numbers after 2 and 6 weeks.
