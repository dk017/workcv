## 4. Reddit and forums

Only answer questions WorkCV's free content actually answers, disclose that you built it, and make the answer useful without the link. Good fits:
- "I got charged by MyPerfectCV / Zety, how do I cancel?" → the cancel guide, in words first, then the link.
- "Is it resume or CV in the UK?", "How long should a UK CV be?" → answer directly; link the UK CV template page only if it adds something.
- "Cover letter example for [role]?" → the matching role section of `/cover-letter-examples-uk`.

Example disclosure line: *"(Disclosure: I built WorkCV, the site I linked — the guide is free, no signup.)"*

Avoid MoneySavingExpert and The Student Room for promotion (their rules restrict it), and AlternativeTo (it declines CV builders).
